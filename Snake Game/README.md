🐍 Snake Game in Python
A classic Snake Game built using Python and the Pygame library. Control the snake to eat food, grow longer, and beat your high score without hitting the walls or yourself!

🚀 Features
Intuitive Controls: Smooth movement using standard Arrow Keys or W/A/S/D keys.

Dynamic Growth: The snake grows longer every time it successfully consumes food.

Score Tracking: Keeps track of your current score and displays your high score.

Collision Detection: Triggers an immediate game-over state if you hit the boundary walls or run into your own body.

🛠️ Prerequisites
Make sure you have the following installed on your system before proceeding:

Python 3.x (Download from python.org)

Pygame library
